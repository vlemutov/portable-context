# Portable Context: начало работы

Это первая рабочая версия общей памяти, которую можно хранить у себя и подключать к разным
агентам. Код предназначен для публичного репозитория; личные архивы хранятся отдельно.

Что уже работает:

- Импорт Claude, ChatGPT, Telegram, активности Gemini и локальных JSONL Codex.
- Хранение оригиналов, редакций и веток; защита от повторной загрузки тех же сообщений.
- Поиск по тексту, Markdown-переписки и редактируемые заметки для Obsidian.
- MCP с чтением и записью; скилл для работы с источниками и обновления памяти.
- Наблюдение за JSONL и очередь доставки новых сообщений с нескольких серверов.

В [README](../README.md) есть команды установки, импорта и подключения. Начни с `init`, затем
загрузи один архив, проверь отчёт, выполни `vault` и открой получившуюся папку в Obsidian.
Заметки памяти создаются тобой или агентом через `write_memory`; программа сама не отправляет
архивы модели и не делает скрытые автоматические выводы о пользователе.

MCP не видит весь диалог автоматически. Для постоянного сохранения нужно подключить сборщик
к тому месту, где агент сохраняет сообщения. Для Ouroboros есть работающая очередь и пример
вызова; встраивание в конкретную версию сервера ещё нужно сделать. Для Claude/ChatGPT/Gemini
в браузере первая версия использует повторные официальные выгрузки. Antigravity не нужен.

Это прототип 0.1, а не завершённый универсальный экспортёр «вообще всего». Пока не реализованы
полный экспорт нового постраничного хранилища Codex, готовые нативные плагины Hermes/OpenClaw/
Ouroboros, автоматическое извлечение фактов, семантический поиск и анализ вложений. Реальные
архивы аккаунтов ещё не проверялись. [Точная матрица возможностей](connectors.md) отделяет
реализованное от будущей работы.

Сохраняй каталог памяти отдельно от публичного GitHub. Он содержит исходные переписки,
вложения внутри ZIP и все сохранённые редакции. Резервная копия нужна для всего каталога,
а не только для видимых Markdown-файлов.
